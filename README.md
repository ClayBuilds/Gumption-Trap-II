Gumption Trap II is an open source autonomous bathymetry robot.
This repository includes main code, CAD, data processing scripts, and other misc info.

Portfolio page links to more details and pictures about this build and its missions:

CNC routing a measured lakebed: https://www.clay-p-mcpherson.com/projects/cnc-routing-bathymetry-from-autonomous-boat/

Bathymetry survey demo: https://www.clay-p-mcpherson.com/projects/gumption-trap-ii-bathymetry-demonstration/

Original build: https://www.clay-p-mcpherson.com/projects/auto-solar-boat-v2-build/
